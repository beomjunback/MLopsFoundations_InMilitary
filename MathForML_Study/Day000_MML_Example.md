## AI-Driven Tech Interview Q&A

### Q1. What is the difference between Joint Probability and Conditional Probability?

- **Answer**: **Joint probability** measures the likelihood of two events occurring at the same time ($P(A \cap B)$). **Conditional probability** measures the likelihood of event $A$ occurring *given that* event $B$ has already occurred ($P(A|B) = \frac{P(A \cap B)}{P(B)}$).

### Q2. How does a B-Tree index optimize query performance in a relational database?

- **Answer**: A B-Tree index structures columns into a balanced search tree. This replaces a full table scan ($O(N)$) with a logarithmic search ($O(\log N)$), drastically minimizing disk I/O bottlenecks during mass data retrieval.
